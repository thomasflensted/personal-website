I build and run all of it alone, from the iOS and Android app in React Native and the web app on TanStack Start to the Go API on Postgres, with coding agents writing most of the code.

- Made every change in the app show instantly, with optimistic updates that roll back if the request fails, and replaced the generic "Something went wrong" screen with errors that say what happened and only offer a retry when one can help.

- Moved event forms and actions from the apps to the API, so most rule changes ship with a server deploy instead of waiting for App Store review.
